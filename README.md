🍽️ Online Food Delivery Analysis Dashboard

📌 Project Overview
This project analyzes an online food delivery dataset using Python, MySQL, and Power BI to generate business insights.

🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Power BI

📊 Dashboard Features
- Total Orders
- Total Revenue
- Average Delivery Time
- Average Delivery Rating
- Average Profit Margin
- Order Status Analysis
- Top Cities Analysis
- Payment Mode Analysis
- Cuisine Type Analysis
- Interactive Slicers

📂 Files Included
- Online_Food_Delivery_Analysis.pbix
- food_delivery_analysis.ipynb
- food_delivery_queries.sql
- dashboard.png

## 📈 Key Insights
- Hyderabad recorded the highest number of orders.
- Delivered orders were significantly higher than cancelled orders.
- The dashboard provides interactive filtering by city, cuisine type, order status, and day type.
